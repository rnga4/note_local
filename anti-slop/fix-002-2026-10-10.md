## Findings

| # | Rule | Status | Where it landed |
|---|------|--------|-----------------|
| 18 | C-4 / R-27 | Fixed | Switching Notes -> Trash (or Archive, or a label) used to paint the previous view's notes for one frame while the fetch was in flight. `NotesApp.tsx` now records the scope the loaded data belongs to (`loadedScope = view\0label`) and, during render, shows the `role="status"` "Loading notes..." whenever the requested scope does not match the loaded one. No post-paint effect, so the stale list is never rendered at all. `NotesApp.tsx:26,41,140,152` |
| 19 | R-31 / R-29 | Fixed | Color-dot border no longer hardcodes hex. `border-[#737373] dark:border-[#a3a3a3]` became `border-[var(--border-strong)]`. The dot edge is a non-text boundary, so it needs >= 3:1; `#737373` clears that on every surface (bottom of the table). `ColorPicker.tsx:20` |
| 20 | R-32 / C-4 | Fixed | `ThemeToggle` now exposes the action it performs: `aria-label` is "Switch to light mode" / "Switch to dark mode", flipping with state. The visible label changes with state, so an `aria-pressed` toggle would have been wrong; an action name is correct. `ThemeToggle.tsx` |
