### LOW (Quality Locks)

18. **C-4 / R-27** — Stale view flash on view/label switch. `NotesApp.tsx:34-51` keeps the previous `notes` array rendered while the new fetch is debounced 200ms, and the loading branch only renders when `notes.length === 0` (`NotesApp.tsx:148`). Observed in the browser: after clicking "Trash", an active note stayed visible about 35ms (and until the fetch resolved) before it disappeared. For Trash, Archive, and label views this briefly shows notes that do not belong to the current view, with no loading cue. Reason: a refresh state is not expressed once data already exists.
19. **R-31 / R-29** — Token drift in `ColorPicker.tsx:20`: the unselected color-dot border is hardcoded `border-[#737373] dark:border-[#a3a3a3]` instead of the `--border-strong` / `--muted` tokens, so a future palette change would not reach it. Reason: the four dot borders are the only chrome colors in the app that bypass the token set.
20. **R-32 / C-4** — `ThemeToggle.tsx:31-39` exposes only the action as its accessible name ("Dark mode" / "Light mode") with no `aria-pressed` or state text, so the current theme is not programmatically conveyed. Visually the label is clear; the gap is screen-reader state.
